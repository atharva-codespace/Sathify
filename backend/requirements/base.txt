# NOTE ON RAZORPAY (Module 8)
# The official `razorpay` SDK is deliberately NOT used. Version 1.4.2 imports
# `pkg_resources` at module load, which setuptools 81+ removed and which does
# not exist on this project's Python 3.13 — the SDK cannot be imported at all
# here. Rather than pin an old setuptools to keep a convenience wrapper alive,
# Module 8 talks to Razorpay's REST API with `requests` and verifies webhook
# signatures with stdlib `hmac`. That is a smaller surface, it removes a
# dependency, and it makes the security-critical path testable without the
# network. See apps/payments/gateway.py.
